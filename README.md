\# RestaurantApp-Team



โปรแกรม Console จัดการข้อมูลร้านอาหาร



\## สมาชิกและหน้าที่

\- A (ชื่อ-นามสกุล): AddRestaurant รับชื่อร้าน ประเภท คะแนน แล้วเพิ่มเข้า List

\- B (ชื่อ-นามสกุล): ShowGoodRating แสดงเฉพาะร้านที่คะแนนตั้งแต่ 4.5 ขึ้นไป

\- C (ชื่อ-นามสกุล): ShowSummary แสดงร้านคะแนนสูงสุดและต่ำสุด



\## วิธีรันโปรแกรม

1\. clone repository: git clone https://github.com/Suphit22/RestaurantApp-Team.git

2\. เปิดไฟล์ RestaurantApp.slnx ด้วย Visual Studio

###### 3\. กด F5 เพื่อรันโปรแกรม
